# 🚗 CarDeal — Frontend Car Dealership Scheduler

A **frontend application** that allows users to schedule test drives for different car models.  
The app stores vehicle and appointment information using cookies and automatically sends the appointment details to the dealership via email.

---

## 🚀 Overview

CarDeal is a fully client-side application designed to make scheduling car test drives simple and intuitive.  

Key features include:

- 📅 Schedule appointments for multiple car models  
- 📝 Store vehicle and appointment information in cookies  
- 💌 Automatically send appointment details to the dealership email  
- 🖥️ Display of user appointment summary  
---

## 🏗️ Functionality

1. User selects a car model from the available list  
2. User fills out appointment details (pick up and return place, initial date, and final date)  
3. Information is stored in cookies for later reference  
4. Appointment details are displayed on the UI dynamically  
5. Email is automatically sent to the dealership with all appointment info  

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)  
- **UI/Styling:** Bootstrap
- **Data Storage:** Browser Cookies  
- **Email Automation:** Frontend logic sending appointment info to dealership email

---

## 🎨 User Flow

1. Open the website  
2. Browse car models  
3. Fill out the book form  
4. Confirm the appointment
5. Select a car  
6. See the appointment summary displayed  
7. Dealership receives an automatic email with appointment info  

---

## 🔐 Security & Considerations

- Sensitive data is stored only in cookies (no backend persistence)  
- Email sending handled via secure client-side integration 
- Form validation to ensure proper input (date, email, contact info)  

---

## 📊 Features Summary

- Multiple car models selection  
- Appointment scheduling and confirmation  
- Dynamic display of selected car and appointment info  
- Automatic email notifications to dealership  

---

## 🎯 Project Goal

To create a **lightweight, interactive, and fully frontend-based car dealership scheduling system** that simplifies the test drive booking process for users and automates communication with the dealership.
